# Learning Tailwind CSS v4

A collection of basic HTML examples created while exploring **Tailwind CSS v4** and its utility-first styling approach.

## Concepts Practiced

- Typography and colors
- Spacing, borders, and rounded corners
- Flexbox and Grid layouts
- Responsive design with breakpoint utilities
- Dark mode styling

## Technologies Used

- HTML5
- Tailwind CSS v4

## About

This repository documents my initial hands-on practice with Tailwind CSS utilities, layout techniques, and responsive styling.

It serves as a reference for foundational Tailwind CSS concepts.
